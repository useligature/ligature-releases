# Ligature releases

Public desktop installers and auto-update feeds for [Ligature](https://useligature.com).

This repository holds **release binaries and update metadata only**. Application source lives in a private repository.

## Downloads

Use the [Releases](../../releases) page for signed and notarized macOS builds for Apple silicon.

Public desktop distribution is temporarily Mac-only. Windows and Debian installers and update feeds are paused; platform development and internal qualification continue separately.

## Updates

Packaged Ligature apps check this repository for updates. Only macOS update feeds are currently published. Do not open issues here for product bugs or feature requests.
