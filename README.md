# Ligature releases

Public desktop installers and auto-update feeds for [Ligature](https://useligature.com).

This repository holds **release binaries and update metadata only**. Application source lives in a private repository.

## Downloads

Use the [Releases](../../releases) page for the latest macOS, Windows, and Linux builds.

During private beta, some platforms may be unsigned. Prefer the build for your OS from the newest published release, and follow any install notes included there.

## Updates

Packaged Ligature apps check this repository for updates. Do not open issues here for product bugs or feature requests.
